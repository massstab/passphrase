# Modern Passphrase Generator

A customizable, web-based passphrase generator that creates strong passwords based on user-defined word lists. Supports uppercase/lowercase letters, special characters, and numbers. Ideal for creating secure passwords.

## Features
- **Word List Support**: Upload a custom word list in `.txt` format.
- **Customizable Passphrase**: Control the number of words, separators, letter casing, and more.
- **Special Characters and Numbers**: Optionally add special characters and numbers for extra security.
- **User-Friendly UI**: Modern, responsive design for a pleasant user experience.

## Installation

1. Download the repository or clone it with Git:
   ```bash
   git clone https://github.com/your-username/passphrase-generator.git
   ```

2. Open `index.html` in your browser to use the generator.

## Usage

1. Upload a **`wordlist.txt` file** containing a list of words. The words can be **separated by spaces** and do **not need to be on separate lines**—they can be in a single line, for example:

   ## Example Word List

   The word list should be in `.txt` format with words separated by spaces. An example word list could look like this:

   ```
   EVENING ACTION ALARM ALL WORK EYES CAR BALL BEER FLOWER FLOOR BOOKS CASTLE COUCH ROOF DRAGON ICE ENERGY RIVER FRANK JOY GUITAR TRADE HOUSE SKY POWER LIGHT DESIRE BRAND NIGHT NOSE CARE ROOM RED STAR BAGS ANIMAL CLOCK FOUR WINE WIND GOAL
   ```

   Words can be chosen freely as long as they are space-separated. Make sure not to use special characters or other separators. You can add as many words as you like to make the passphrase more secure.

2. Select the number of words and adjust options such as letter casing, special characters, and numbers.

3. Click "Generate Passphrase" to create a new passphrase.

4. Copy the passphrase using the "Copy to Clipboard" button.
